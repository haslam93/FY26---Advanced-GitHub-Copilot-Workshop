# Module 10 - Hands-on Lab

> **Time:** 90 minutes
> **Format:** Five independent exercises using the repository's live customization, MCP configuration, cloud workflow, and runnable samples.

| Exercise | Topic | Time |
|---|---|---:|
| [01](exercises/exercise-01-customization.md) | Instructions, prompt files, custom agents, and skills | 15 min |
| [02](exercises/exercise-02-cloud-agent.md) | Cloud agent from issue to reviewed pull request | 20 min |
| [03](exercises/exercise-03-mcp-github.md) | GitHub and Playwright MCP | 15 min |
| [04](exercises/exercise-04-modernization.md) | Legacy-code analysis and migration planning | 15 min |
| [05](exercises/exercise-05-testing.md) | Unit and Playwright test generation | 20 min |

Allow five minutes for setup with the [prerequisites checklist](docs/prerequisites.md).

## Lab rules

- Use a fork or disposable branch for write exercises.
- Use synthetic data only.
- Review every tool call before approval.
- Treat generated code and reviews as proposals.
- Run the validation command in each exercise.
- Skip cloud or preview features if policy does not enable them.

The simple [`demo-nodejs/`](../demo-nodejs/) app is the shared demo target for several exercises.
