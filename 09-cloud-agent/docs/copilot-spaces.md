# Copilot Spaces

Copilot Spaces is a GA feature for curated, shareable context.

A Space can combine:

- repositories and selected files
- issues and pull requests
- instructions and guidance
- automatically updated GitHub content

Use Spaces when a recurring conversation needs a maintained context set without copying information into every prompt.

## Workshop example

Create a Space containing:

- the workshop README
- Modules 01 through 04
- the Node.js demo README
- the cloud-agent exercise

Ask:

```text
Compare the local agent, Copilot CLI, Copilot app, and cloud-agent workflows in this workshop. Cite the source files in the Space.
```

IDE use requires the remote GitHub MCP server and the relevant Copilot Spaces toolset. Access follows the permissions of the underlying GitHub content.
