# Customization and Extensions

The app can use the same core customization concepts as Copilot CLI:

- repository and agent instructions
- custom agents
- skills
- MCP servers
- plugins
- automations
- Chronicle
- canvas extensions

Inspect extensions before enabling them. A plugin or skill can include scripts, tools, or instructions that affect agent behavior.

## Workshop check

Open the environment or customization view and confirm that the repository exposes:

- `.github/copilot-instructions.md`
- `.github/agents/workshop-reviewer.agent.md`
- `.github/skills/presentation-qa/SKILL.md`
- `.vscode/mcp.json`

Client support and naming can change, so use the app's current UI as the source of truth.
