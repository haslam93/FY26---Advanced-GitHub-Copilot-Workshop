# Cloud Sandboxes

Cloud sandboxes let supported app sessions run in a hosted environment instead of a local worktree.

This capability is public preview. Before using it:

- verify account and organization policy
- confirm repository and network access
- use only synthetic workshop data
- review secrets and environment configuration
- understand how results return to the repository

For a stable workshop, demonstrate local worktrees first and describe cloud sandboxes as an optional preview.
