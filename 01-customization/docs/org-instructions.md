# Organization Guidance

Organization-wide policies and approved customization can provide a baseline for many repositories. Repository instructions should add project-specific facts rather than copying the entire organization policy.

Typical organization guidance:

- secure coding requirements
- approved dependency sources
- data-handling rules
- required review or validation steps
- links to maintained engineering standards

Keep policy ownership clear. If a central rule changes, update the maintained source rather than scattering stale copies across repositories.

Availability and configuration depend on the organization's Copilot plan and policy settings. Verify the current [GitHub Copilot customization documentation](https://docs.github.com/en/copilot/customizing-copilot) before a workshop.
