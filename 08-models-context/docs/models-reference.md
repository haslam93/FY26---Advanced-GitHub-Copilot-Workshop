# Live Model Reference

Do not copy a static model table into workshop material. Models, availability, request multipliers, and plan eligibility change too quickly.

Use these live sources during delivery:

- [Supported AI models in GitHub Copilot](https://docs.github.com/en/copilot/reference/ai-models/supported-models)
- [Requests in GitHub Copilot](https://docs.github.com/en/copilot/concepts/billing/copilot-requests)
- The model picker in the current Copilot surface
- `/model` in GitHub Copilot CLI

Before a workshop, capture only the models you plan to demonstrate and verify access with the account and policy used in the room.
