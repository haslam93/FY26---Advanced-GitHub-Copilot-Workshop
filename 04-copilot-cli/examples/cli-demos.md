# Copilot CLI Demo Runbook

Run these from the repository root.

## 1. Environment and instructions

```text
/env
Explain which instruction files are active and how they affect this repository.
```

## 2. Plan and implement

```text
/plan Add an open/completed filter to demo-nodejs. Include tests and preserve the dependency-free design.
```

Review the plan, then use guided execution or switch to Autopilot mode.

## 3. Independent critique

```text
/rubber-duck
```

Ask the critic to focus on correctness, accessibility, and unnecessary complexity.

## 4. Research

```text
/research Compare the current GitHub Copilot customization surfaces and cite official documentation.
```

## 5. Parallel analysis

```text
/fleet Review separate workshop modules for broken links and stale terminology. Do not edit files.
```

## 6. History and sharing

```text
/chronicle
/share
```

Demonstrate `/resume`, `/search`, or `/rewind` if time permits.

## 7. GitHub handoff

```text
/delegate --base main
```

Explain that delegation sends the session to GitHub so the cloud agent can work and create a pull request.
